# 文档模式的创作者到日历链接流程

2026-09-10。新存储已接入创作者保存、范围与类型设置、暂停/恢复、删除影响和删除、主动刷新、共享频道轮询、规则匹配、待确认/忽略、个人屏蔽与固定，以及既有个人ICS发布。当前验证为独立本地适配器和合成上游；开发、生产云目标仍是 Cosmos Serverless + Periodic，Azure资源未创建。

## 所有权与命令

个人配置是关注和覆盖的权威。保存配置、精确幂等回执、日历投影任务与创作者协调任务同个人分区提交；重复已完成命令不再次解析频道。公共频道资料独立保存，失败的个人配置命令可能留下已验证的公共频道资料，不能把这描述为跨分区事务。

`channel:<channelId>`分区维护公共频道状态、视频引用和一个共享发现任务。个人关注登记在辅助目录，消费者始终重新读取账号和当前配置；目录不是权限依据。多个账号关注同一频道只产生一次活动抓取，各自的匹配、链接、屏蔽和待确认结果留在自己的分区。

配置中的球队/赛事范围、频道类型或个人覆盖变化会重新处理已知视频，不要求每次配置操作重新调用YouTube。配置导入接受已经解析过的频道，未知频道或关联范围保留为unresolved，不能静默忽略。

每个个人创作者关注必须绑定至少一个当前已关注的球队或赛事。新增和编辑接口拒绝空范围及未关注对象，并在解析 YouTube 频道前完成检查，避免无效请求消耗配额。取消关注对象时，服务端从每个创作者范围中同步裁剪该对象；仍有其他范围的创作者继续保留，范围变空的创作者才自动取消。旧版本的空范围曾表示“我的所有关注”，统一配置保存时会把它具体化为当时仍保留的关注对象。Web 只展示当前关注对象供选择，关注变更预览会列出同步取消的创作者。

## 持久发现步骤

一个频道任务分步执行上传列表、视频详情、已保留视频补查与频道资料。每一步最多一次HTTP，完成后把下一步写回同一持久任务；分页游标、14天起始回看窗口、尝试次数和共享冷却都保留。队列重投或进程重启根据已提交步骤继续，额度等待不会重新读取已经成功的上传列表页。

视频详情最多50条。全部身份、字段、日期和可用状态先验证，再准备不可变内容块，最后把最多50个视频引用、频道状态、下一步和通知任务同分区提交。50条长中文/emoji简介也不会挤破原子批大小。准备好的孤立块目前不自动回收，原始历史元数据清理是后续隐私工作。

上传列表中暂时没有某个旧视频不表示删除；保留视频仍经videos查询验证。失败或不完整响应不能清空先前视频；确认不可用后撤下链接，恢复可用时遵守已有人工固定与屏蔽。SQL和文档模式共用 `youtube_content_rules` 规范化与 `matching.evaluate` 规则，不存在客户端匹配规则副本。

账号至少仍有一个活跃关注时才继续抓取。首次成功后每6小时补查；本地worker启动/每分钟检查、Azure每5分钟Timer调用同一服务。手动刷新遵守已有冷却，活动任务复用。额度等待不消耗失败预算；其他连续失败进入冷却，最多5次尝试后当前任务失败。失败记录无法保存则抛出错误交由租约/队列恢复，不能仅确认任务完成。

## 个人匹配与发布

频道变化每页处理50个相关owner，个人任务每页安排25个视频，每次事务最多更新20个视频/比赛关联。每个事务带账号ETag、任务租约、关联记录ETag及投影outbox。处理时重新读取当前配置、视频和赛程版本；配置改变后从新版本重算。公共频道和个人分区之间依靠后续任务收敛，不承诺跨分区瞬时一致。

候选和解释沿用既有规则：只有明确对象、内容阶段和消歧证据才自动附加，模糊内容进入待确认。待确认读取和提交都会检查视频/比赛版本及当前频道范围；其他账号不能读取或确认个人关联。用户忽略、屏蔽、固定和确认优先于新抓取。标题变化不再匹配时撤回自动链接，日历事件UID保持稳定；导入的旧关联ID也保留。

暂停保留已有链接并停止新发现；手动删除或因最后一个绑定对象被取消而自动删除创作者时，未固定的自动链接退出个人日历，手动/已固定链接保留。移除后的待确认条目立即不再展示。账号删除、历史关联与元数据物理清理仍属后续迁移，不能把删除创作者说成完整账号擦除。

```sh
uv run python -m experiments.document_creators_ui
uv run python -m experiments.document_creators_verify --output data/document-creators-http-final-20260910.json
```
