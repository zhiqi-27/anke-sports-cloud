# 视频匹配规则与离线回放

2026-09-10，当前规则 `matching-v2`。适用 T17/T18、QA-18/QA-19/QA-20；真实 YouTube 样本与 98% 自动关联精确率仍未验收。

## 行为变化

旧规则把标题和简介拼成一段判断。视频标题为“日常记录”，简介列出旧的 `Lakers Warriors 2026-09-10 preview`，也可能自动附到比赛；`9-10` 比分及混用日期也曾提供错误的消歧证据。

v2 自动附加要求标题自身明确双方球队或大奖赛分场次、前瞻/复盘阶段；日期消歧也取自标题。简介仍帮助生成待确认候选，排斥词仍检查标题和简介。仅简介支持的相关视频允许人工确认。标题改变或规则重算撤下不再符合条件的自动链接；人工确认、固定与屏蔽优先。

支持 ISO 完整日期、中文年月日和英文月份名称。`9/10` 可表示 9 月 10 日或 10 月 9 日，会保留人工确认；`13/09` 只有有效的日/月解释。短横线和冒号比分不能充当日期。冲突日期拒绝；多个有效日期无法逐场对应时进入待确认。同一天同对手多场、F1 未指定分场次仍需消歧。

任意多场视频的段落解析、其他语言日期和完整球队/分站别名尚未实现。标题缺少必要信息可能降低自动覆盖，相关视频仍可人工附加。后续按真实标注集测量分组精确率、召回率与覆盖率后扩展。

## 回放命令

```sh
uv run python -m scripts.replay_matching tests/fixtures/matching-synthetic-v1.json --output data/matching-report.json
uv run python -m scripts.replay_matching tests/fixtures/matching-synthetic-v1.json --compare evidence/matching-replay-before-2026-09-10.json --output data/matching-comparison.json
```

每次指定尚不存在的输出文件。工具只读取给定元数据，不导入应用数据库或认证配置，不联网、不写关联。输入显式区分 `synthetic` / `human_labeled` 并保留标签说明，拒绝未知字段、重复 ID 和错误引用。真实样本须先脱敏，并按平台要求维护；不要提供私有 Feed 地址、密钥或业务账号数据。

报告包含输入文件哈希、完整规则文件哈希、候选原因与判定、TP/FP/FN、自动精确率/召回率/覆盖率，以及运动和语言分组。没有自动关联时精确率为 null，不能把全部拒绝算为 100%。比较要求数据文件哈希一致，逐条列出决策变化，不自动重算线上数据。报告不复制标题/简介；case/event ID 也须使用非敏感标识。

## 合成回归与边界

32 条显式案例覆盖简介推广、比分、短日期歧义、旧赛季、中文/英文日期、跨时区、连续场次、F1 和缺少阶段。标签保留一条仅简介写明阶段的相关视频，用于计入未自动附加造成的召回损失。

| 合成集结果 | v1 | v2 |
| --- | ---: | ---: |
| 正确自动关联 | 9 | 13 |
| 错误自动关联 | 7 | 0 |
| 未自动附加的正确关联 | 5 | 1 |
| 自动精确率 | 56.25% | 100%（仅 13 条自动结果） |
| 自动召回率 | 64.29% | 92.86% |
| 自动附加视频覆盖率 | 50% | 40.63% |

该集针对已知边界编写，样本少且不是独立真实分布，**不能据此声称真实视频达到 98%**。至少 200 条真实人工标注样本、运动/语言分层和线上错误率仍需验收。工具的 `meets_product_acceptance` 始终为 false，数据集指标不自行替代产品验收。

证据：[v1 回放](../evidence/matching-replay-before-2026-09-10.json)、[v2 与逐条差异](../evidence/matching-replay-after-2026-09-10.json)。v1 从本次变更前 Git HEAD 导出到忽略目录作基线，未改历史版本。
