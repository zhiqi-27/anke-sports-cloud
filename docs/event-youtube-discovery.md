# 已停用：按比赛自动搜索 YouTube 视频

更新：2026-09-16。此页只保留已部署开发版的历史行为。当前本地候选版本已进一步删除视频入口、公开接口、Timer、Queue执行与日历投递；并非改用另一种视频发现方式。该变更尚未部署。

## 产品行为

- 历史版本的用户可关注球队、赛事或具体比赛，不需要关注创作者；“旧创作者接口暂留一版兼容”也只是当时的过渡记录。当前接口不保留该兼容层，当前定时任务和新发现链路均不读取创作者配置。
- 用户可在 `before_24h`、`before_3h`、`after_3h`、`after_18h` 中选择 0–2 个搜索时间，默认赛前 24 小时和预计结束后 3 小时。
- 查询由比赛参与者、标题、运动及时间窗口确定性生成，不调用 AI。发现只调用 YouTube Data API `search.list`；没有 AnySearch、Google 网页搜索或其他网页补漏。
- 同一 `(event_id, event_updated_at, window, query_version)` 在所有用户间只运行一次。任务错过计划点时最多补跑 6 小时；未知时间、演示、取消或延期比赛不创建搜索。
- 每次搜索读取一页最多 25 条，随后用 `videos.list` 校验公开状态、频道和观看量，并读取最多 12 条公开顶层评论。任一关键上游失败会让任务重试，旧日历内容不清空。
- 每个 `视频 × 比赛` 独立经过确定性冲突过滤与 Gemini 评分。`≥0.90` 全部自动挂入，不限数量；`0.55–0.899` 进入待确认；`<0.55` 静默排除。

## 标签和信誉

每条评估分别保存：

- `system_labels`：确定性标签，当前支持 `✅官方频道` 与 `🔥热门`；
- `ai_content_labels`：Gemini 输出的内容标签；
- `display_labels`：系统标签优先，再补 AI 标签，最多 3 个。

官方频道不能由 AI 猜测。维护接口要求 HTTPS 证据、维护者、核验时间及可选失效时间。热门标签在同一搜索批次至少 5 条视频时计算，使用 `log(views+1)/sqrt(age_hours+2)` 的第 90 百分位且观看量至少 10,000，不作为相关性置信度。

`channel_reputation` 当前记录发现次数、唯一评估对数量及自动/备选/排除数量。用户确认、忽略或移除 discovery 视频会在个人分区写入不含身份公开信息的 `channel_feedback`。这些统计本批只记录，不进入模型输入或自动阈值；历史准确率和移除率需要在真实样本积累后再聚合校准。

## 配额与失败

- 现有项目级 YouTube 总请求账本继续生效。
- `search.list` 另有每日 80 次软上限，对应 Google 的独立搜索请求额度预留余量。搜索上限用尽只暂停新搜索，不阻止已经发现的视频详情读取。
- 任务使用事件 `updated_at` 作为 revision fence。比赛在搜索或发布前变化会把旧 run 标为 stale，不写入个人日历。
- 取消/延期比赛不显示未固定的 discovery 内容；用户固定的链接保留。用户 block/remove 后，重复搜索可以更新共享评估，但个人链接不会重新显示；固定链接的标题和标签不会被后台覆盖。

## 当前验证

`tests/test_document_discovery.py` 覆盖确定性查询、最多两个时间、两用户共享一次搜索、五条自动结果全部挂入、官方/热门/AI 标签顺序，以及固定/移除不被重放覆盖。真实英超、NBA、F1 样本、80 次额度边界的云端行为、Cosmos RU、Queue 超时和 iPhone 点击 YouTube App 仍待部署后验证。
