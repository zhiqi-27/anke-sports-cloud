# 官方直播入口与维护

本地实现，真实场次来源和设备兼容性仍待验收。维护者从 `/maintenance` 选择已有比赛，保存草稿，核对官方证据、内容类型、地区与观看条件，再明确发布。该页面不是直播聚合器，不发现或播放媒体流。

## 身份与发布

- `ANKE_SPORTS_MAINTAINER_IDS` 是经过 Firebase 验证后的 UID 白名单，默认 `[]`；本机体验账号也不会自动成为维护者。Chrome/MCP 的个人权限不能升级为公共维护权限。
- 公共 `Link` 与 `BroadcastRecord` 分开保存。草稿不对外展示；修改已发布记录时，原审核版本继续生效，重新发布后才替换。比赛身份不可编辑，所有写入使用版本冲突检查。
- 发布需要证据页面、核对说明、明确确认和未来 7 天内的复查期限。审核记录、业务变化与个人投影 outbox 在同一事务提交。撤回和到期只移除入口，不取消比赛、不更换 UID。
- 内容区分比赛直播、预约、播出信息、无比赛画面的同步解说、官方完整回放。仅比赛直播和预约可成为 ICS 主 URL；其他类型使用明确标签。地区未知不会推断为全球可用，个人观看地区过滤与 block/pin 继续有效。
- 每场 Feed 最多 2 个直播或同步解说、3 个前瞻、3 个复盘；个人与公共链接按规范 URL 去重。网络状态和设备观察不会单独增加 ICS 版本，实际发布内容变更才更新投影。

## URL 注册表与后台检查

`app/platforms.py` 集中维护允许的 YouTube、NBA、F1、UEFA、FIFA、ESPN、bilibili 主机和候选路径。`GET /api/v1/platforms` 返回 `candidate_only` 和设备未验证状态。域名或候选路径通过，只证明它在允许检查的范围内；仍需维护者核对比赛、发行方身份及观看条件。特别是非 YouTube 平台，具体路径规则和跨客户端兼容性尚待真实样本收紧。

手动链接、MCP、Chrome 和维护入口共享 URL 规范化：HTTPS、主机白名单、无账号密码、无凭据或跳转参数、无媒体流或媒体片段路径。网络检查只发 HEAD：DNS 结果全部必须是公网地址，连接固定的已验证 IP，TLS 校验原始主机名；不跟随跳转、不发送账号凭据、不下载正文。不接受“打开首页”作为场次证据。

`ANKE_SPORTS_BROADCAST_CHECKS_ENABLED=false` 默认关闭自动联网巡检。维护者仍可明确请求单次检查。启用后一般 6 小时复查，比赛开始前 24 小时提高到约 1 小时；失败稍后重试。HTTP 可达不等于 App 直达或账号能够播放。401/403/451、暂时故障和不支持 HEAD 不直接移除入口；至少间隔 5 分钟的两次 404/410、危险结果或需要重新核对的跳转会撤下入口。重新核验发布后恢复。

审核到期撤回独立于联网开关。本地 worker 每分钟、Azure 内容 timer 每 5 分钟调度，随后由 outbox 发布变更；不是到期瞬间的客户端撤回承诺。调度当前扫描已发布记录，需在云端规模验收前验证批处理、并发及负载。操作审计保留在 `broadcast_audit`；界面显示最近 30 条。

## 设备证据

分别记录内容正确、进入 App 的具体内容、实际播放三层结果，绑定链接 URL、平台 App/系统/日历客户端版本、地区、时间、安装情况和账号条件。默认均为未测试。URL 或内容类型变化会清除旧观察；网页展示具体观察条件，不生成笼统的“客户端直达”承诺。私人验收记录编号仅维护者可见。

## 本地复现与恢复

主体验库不会插入合成官方入口。独立复现：先在客户端 `npm run build`、`npm run start -- --port 3002`，再在本仓运行 `uv run python -m experiments.broadcast_ui`，打开 `http://localhost:3001/maintenance` 并进入本地体验。夹具使用临时 SQLite、合成比赛和合成维护者；HEAD 固定返回合成可达，不会访问平台，停止进程后删除临时库。

迁移 `7b26efb1d423` 只增加审核记录和审计两张表。SQLite upgrade/check/downgrade/upgrade 已验证，MySQL 仅检查离线 DDL。云端迁移仍需独立环境及备份恢复演练。本次本机备份为 `data/before-broadcast-20260910-002301.db`（0600）；恢复时先停止 API/worker，并确认保留备份后产生的数据，再恢复备份与对应代码版本。
