# 日历赛果标题

## 规则

- 供应商只写入独立的 `Event.result`，不改写中性的 `Event.title`。
- 仅足球、篮球在供应商明确返回完赛状态和双方比分后生成赛果；缺分、未完赛、取消或延期不生成。
- 防剧透默认开启。开启时，按每个关注球队分别隐藏该球队最近一场已结束比赛的结果；更早的已结束比赛仍显示赛果。
- 手动加入但未被球队关注覆盖的比赛不受防剧透影响；关闭防剧透后，个人日历中所有有完整比分的已结束比赛显示赛果。
- 赛果标题只进入该用户的事件读取和个人 ICS/Feed 投影；公共日历、未加入“我的关注”的“全部比赛”和其他用户仍拿到中性标题。
- 结果刷新窗口为开赛前 2 小时至开赛后 4 小时，窗口内每 15 分钟检查一次；其他时间沿用 6 小时供应商刷新。

## 边界

F1 当前上游适配器只提供赛程和车队参与者，没有可用于该标题的正赛名次结果，因此不拼接虚构比分；后续接入明确结果源后再扩展赛车的结果摘要。
