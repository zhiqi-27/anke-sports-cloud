# 个人 Feed 取消关注隐藏语义 · 2026-09-13

## 用户反馈与结论

iPhone 收到个人 Feed 更新后，把已取消关注的 F1 未来比赛显示为删除线和“已取消日程”。这不是客户端未刷新：旧实现会保留同一 UID，并把用户移除投影序列化为 `[已移除]` + `STATUS:CANCELLED`。

当前本地候选实现改为：

- 用户取消关注或显式排除：个人 Feed 完整快照不再包含对应未来事件，日历客户端应直接隐藏。
- 已发生且未显式排除的历史比赛：继续保留。
- 赛事来源本身取消：活动投影仍输出 `STATUS:CANCELLED`，继续向用户展示真实取消信息。
- 公共 Feed 的撤下墓碑：保持原行为，未被个人语义影响。
- 被移除投影仍在服务端保留；以后重新关注时复用原投影 ID 和稳定 UID。

## 验证

- SQL 与文档/Cosmos 路径、关注预览、显式排除、Feed 地址轮换、并发发布和公共 Feed 墓碑：60 项定向回归通过。
- 全量：383 passed / 2 skipped；2 条为既有第三方依赖弃用警告。
- `uv run ruff check .` 与 `git diff --check` 通过。

## 证据边界

这是本地候选实现，尚未部署 Azure，也没有修改真实账号或个人 Feed。部署后需要让当前账号触发一次 Feed 重建，再在 iPhone/Mac 刷新 Anke Sports 日历，确认未来 F1 事件消失；历史 F1 和赛事源真实取消仍应按上述语义保留。
