# 个人链接与大配置的文档存储验收

2026-09-10。开发、生产均按用户最新决定采用 Cosmos NoSQL **Serverless + Periodic**；本批是独立本地适配器验证，Azure 资源未创建。原主预览、Firebase 账号和其他产品资源未修改。

## 已验证

- 完整后端回归 **288 passed / 2 skipped**，15.51秒；跳过项为条件 MySQL 检查，两条既有 Starlette/AnyIO 弃用警告。Ruff、完整 OpenAPI/配置 schema 比较通过。客户端仅 README/STATE 更新，没有重复构建。
- 新增11项内容测试：手动附链与精确幂等响应、屏蔽/再次附加/固定、跨用户/游客隔离、非法URL、事务中途失败回滚、单场选择/重置/取消/版本冲突、导入预览与账号绑定、合并/替换/数量上限、坏块与删除后的重放。
- 2,000条长链接规则超过单文档容量，通过真实本地仓储的尺寸校验、分块导入和大回执重放。新连接重读、发布、轮换/暂停/恢复保持完整配置；分块或最终提交失败保留旧配置/Feed/任务。中文、emoji、引号和反斜杠跨UTF-8分块后摘要相同。
- 在读取链接期间插入并发屏蔽命令，旧发布快照被拒绝，旧Feed不变；重试读取新状态后正确发布。

## UI 与独立后台读回

[演示比赛](http://localhost:3007/calendar?event=document-demo-03)：浏览器进入本地体验→单场加入→手动附加明确标注的合成YouTube地址→移除→再次附加仍屏蔽。日期、双方、来源、视频地址均为夹具，未访问该外部地址，不是有效视频、匹配关系或播放证明。

实际HTTP客户端另建临时本地会话，读取同一体验账号：附加后配置revision2、已发布1条事件、SEQUENCE2；屏蔽和再次附加后revision3、同UID、SEQUENCE3、描述中无该URL。条件请求304、HEAD200；脚本会话已退出，浏览器会话保留。独立worker实际消费持久队列，非测试函数直接代替后台。

IAB标签29已保留；抽屉和描述预览已检查，console error为空。新API/HTML代理session70275/PID91533，worker PID91534，端口3007。临时库由实验管理，停止实验清理；旧3006及主/Firebase实例未重启。

## 修复与边界

初轮检查发现链接payload的kind与文档构造参数冲突，已修复。其余初轮失败为测试断言的HTTP错误包装层级、字符串/字节比较；最终完整回归在修复后执行。导入预览对旧配置深拷贝，防止预览修改内存对象；合并及手动附加超限均明确拒绝，不留下半次业务写入。

不可变块先准备、原子指针后提交，不承诺跨分区事务。孤立块与历史任务尚未GC，用户链接列表仍按用户分页加载，长期成本未验收。创作者/YouTube、直播、公共Feed、删除/OAuth/MCP等文档路径仍未迁移，原SQL完整路径保留。真实Cosmos/RU/429/权限、Azure触发器、Periodic恢复、SQL迁移和手机日历均待验；没有push或部署。
